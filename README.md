# transformers-ai360-practice

**files-guide:**
* `train_large_model.ipynb` – trained on a $2.000.000$-element subset of the **WMT 2016** dataset, acheiving $24.14$ **BLUE** score with mediocre tokenization: unknown tokens are translated poorly. (i. e. `Tehran's` is unknown so it is represented like `Teh ran 's`)
* `experiments.ipynb` – contains notebook for all the experiments described in the poster, trained on a **multi30k** (DE $\rightarrow$ EN) dataset.
